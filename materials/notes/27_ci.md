# D27 补课：CI只运行它能验证的事

本次编写的补课讲义，不是 Hello-Agents 原文。例子与通过线属于课程设计。

## 官方补充资料
- GitHub Actions Python官方教程：https://docs.github.com/en/actions/tutorials/build-and-test-code/python

## 今日只学以下内容
### 1. 工作流职责
checkout源码；setup-python选择你的固定版本；安装requirements-test.txt；运行unittest。
使用官方当前教程的action主版本并记录，不能按记忆编一个不存在的版本。
### 2. 测试分层
tests目录只放fake模型、临时文件/数据库、可离线执行的测试。
integration_tests放MCP进程等集成测试；真实API单独手工执行。
测试模块导入不能自动下载模型或访问账户。
### 3. 远端证据
没有push和远端run结果，只能写“本机离线测试通过”。
把一个断言故意写错观察失败，恢复后再提交。跳过不能计为通过。

## 停止条件
能说明输入、返回值、一个失败分支；回到当天作业实现，不继续拓展新框架。
