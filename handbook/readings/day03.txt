 1359 | ### 7.5.1 工具基类与注册机制设计
 1360 | 
 1361 | 在构建可扩展的工具系统时，我们需要首先建立一套标准化的基础设施。这套基础设施包括Tool基类、ToolRegistry注册表，以及工具管理机制。
 1362 | 
 1363 | （1）Tool基类的抽象设计
 1364 | 
 1365 | Tool基类是整个工具系统的核心抽象，它定义了所有工具必须遵循的接口规范：
 1366 | 
 1367 | ````python
 1368 | class Tool(ABC):
 1369 |     """工具基类"""
 1370 | 
 1371 |     def __init__(self, name: str, description: str):
 1372 |         self.name = name
 1373 |         self.description = description
 1374 | 
 1375 |     @abstractmethod
 1376 |     def run(self, parameters: Dict[str, Any]) -> str:
 1377 |         """执行工具"""
 1378 |         pass
 1379 | 
 1380 |     @abstractmethod
 1381 |     def get_parameters(self) -> List[ToolParameter]:
 1382 |         """获取工具参数定义"""
 1383 |         pass
 1384 | ````
 1385 | 这个设计体现了面向对象设计的核心思想：通过统一的`run`方法接口，所有工具都能以一致的方式执行，接受字典参数并返回字符串结果，确保了框架的一致性。同时，工具具备了自描述能力，通过`get_parameters`方法能够清晰地告诉调用者自己需要什么参数，这种内省机制为自动化文档生成和参数验证提供了基础。而name和description等元数据的设计，则让工具系统具备了良好的可发现性和可理解性。
 1386 |

 1392 | class ToolParameter(BaseModel):
 1393 |     """工具参数定义"""
 1394 |     name: str
 1395 |     type: str
 1396 |     description: str
 1397 |     required: bool = True
 1398 |     default: Any = None
 1399 | ````
 1400 | 这种设计让工具能够精确描述自己的参数需求，支持类型检查、默认值设置和文档自动生成。

 1402 | （3）ToolRegistry注册表的实现
 1403 | 
 1404 | ToolRegistry是工具系统的管理中枢，它提供了工具的注册、发现、执行等核心功能，在这一节我们主要用到以下功能：
 1405 | 
 1406 | ````python
 1407 | class ToolRegistry:
 1408 |     """HelloAgents工具注册表"""
 1409 | 
 1410 |     def __init__(self):
 1411 |         self._tools: dict[str, Tool] = {}
 1412 |         self._functions: dict[str, dict[str, Any]] = {}
 1413 | 
 1414 |     def register_tool(self, tool: Tool):
 1415 |         """注册Tool对象"""
 1416 |         if tool.name in self._tools:
 1417 |             print(f"⚠️ 警告:工具 '{tool.name}' 已存在，将被覆盖。")
 1418 |         self._tools[tool.name] = tool
 1419 |         print(f"✅ 工具 '{tool.name}' 已注册。")
 1420 |         
 1421 |     def register_function(self, name: str, description: str, func: Callable[[str], str]):
 1422 |         """
 1423 |         直接注册函数作为工具（简便方式）
 1424 | 
 1425 |         Args:
 1426 |             name: 工具名称
 1427 |             description: 工具描述
 1428 |             func: 工具函数，接受字符串参数，返回字符串结果
 1429 |         """
 1430 |         if name in self._functions:
 1431 |             print(f"⚠️ 警告:工具 '{name}' 已存在，将被覆盖。")
 1432 | 
 1433 |         self._functions[name] = {
 1434 |             "description": description,
 1435 |             "func": func
 1436 |         }
